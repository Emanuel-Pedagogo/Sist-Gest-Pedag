Política de Privacidade — SACP

Sistema de Apoio à Coordenação Pedagógica

Última atualização: [DATA DE PUBLICAÇÃO]

Esta Política de Privacidade explica como o SACP — Sistema de Apoio à Coordenação Pedagógica ("SACP", "nós" ou "aplicativo") coleta, usa, armazena e protege dados pessoais, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018).

1. Quem é o responsável pelos dados

O SACP é operado por [NOME DA PESSOA OU EMPRESA RESPONSÁVEL], que atua como controlador dos dados pessoais tratados por meio do aplicativo, em conjunto com a(s) escola(s) que utilizam o sistema para gestão pedagógica.

Contato: [e-mail de contato]

2. Quem usa o SACP

O SACP é destinado a coordenadores pedagógicos e professores (usuários adultos), para apoio à gestão escolar. Crianças e adolescentes não acessam o aplicativo diretamente — seus dados são inseridos e consultados exclusivamente por profissionais da escola, no exercício de suas funções.

3. Quais dados coletamos

3.1 Dados do usuário do aplicativo (coordenador/professor)

  • Nome e e-mail, usados para criar sua conta e fazer login
  • Senha (armazenada de forma criptografada) ou login via conta Google
  • Foto de perfil, quando o login é feito com a conta Google

3.2 Dados de alunos, inseridos pela escola

Para permitir o acompanhamento pedagógico, a escola cadastra no sistema:

  • Nome completo e data de nascimento do aluno
  • Matrícula e turma
  • Nome e contato do responsável pelo aluno
  • Notas escolares e frequência (faltas)
  • Registros de ocorrências pedagógicas (ex.: observações de sala de aula)
  • Sondagens de nível de leitura e escrita, incluindo fotos de atividades escolares quando anexadas
  • Informações de atendimento educacional especializado (AEE), quando aplicável ao aluno

3.3 Dados processados por inteligência artificial

Alguns recursos do SACP usam inteligência artificial (Google Gemini) para agilizar tarefas administrativas, como:

  • Gerar um resumo pedagógico a partir do histórico do aluno
  • Extrair automaticamente notas de boletins em PDF
  • Ler fotos de sondagens de leitura/escrita e sugerir o nível identificado

Nesses casos, os dados necessários (texto do boletim, foto da sondagem, ou dados resumidos do aluno) são enviados à API do Google Gemini apenas no momento em que o profissional aciona a função, processados para gerar o resultado, e não são usados pelo Google para treinar seus modelos de IA públicos (conforme os termos comerciais da API do Gemini). Recomendamos a leitura da política de dados da API do Gemini.

4. Para que usamos esses dados

  • Permitir o cadastro, login e uso do sistema pelos profissionais da escola
  • Organizar informações pedagógicas dos alunos (notas, frequência, ocorrências, sondagens)
  • Gerar relatórios, gráficos e resumos para apoiar decisões pedagógicas
  • Cumprir obrigações legais de registro e guarda de informações escolares

Não utilizamos os dados para publicidade, venda a terceiros, ou qualquer finalidade fora do contexto pedagógico.

5. Com quem compartilhamos os dados

Os dados são compartilhados apenas com prestadores de serviço que ajudam o SACP a funcionar:

  • Supabase — provedor de banco de dados, autenticação e armazenamento de arquivos usado pelo SACP. Os dados ficam hospedados nos servidores do Supabase.
  • Google (API Gemini) — usado apenas para os recursos de inteligência artificial descritos no item 3.3.

Não vendemos, alugamos ou compartilhamos dados pessoais com terceiros para fins comerciais ou de marketing.

6. Base legal (LGPD)

O tratamento de dados no SACP se baseia em:

  • Execução de contrato — entre a escola/instituição e o responsável pelo SACP, para prestação do serviço de gestão pedagógica.
  • Cumprimento de obrigação legal ou regulatória — registros escolares que as instituições de ensino devem manter.
  • Legítimo interesse — para o acompanhamento pedagógico dos alunos pela própria escola em que estão matriculados.

7. Como protegemos os dados

  • Conexão criptografada (HTTPS) entre o aplicativo e os servidores
  • Controle de acesso: cada usuário só acessa dados da(s) escola(s) e turma(s) às quais está vinculado
  • Senhas armazenadas de forma criptografada, nunca em texto puro

8. Por quanto tempo guardamos os dados

Os dados dos alunos são mantidos enquanto durar o vínculo do aluno com a escola e pelo prazo adicional necessário para cumprir obrigações legais de guarda de registros escolares. A escola responsável pode solicitar a exclusão de dados específicos a qualquer momento, respeitando eventuais obrigações legais de retenção.

9. Direitos do titular dos dados

De acordo com a LGPD, qualquer titular de dados (ou responsável legal, no caso de alunos menores de idade) pode solicitar:

  • Confirmação da existência de tratamento de dados
  • Acesso aos dados armazenados
  • Correção de dados incompletos, inexatos ou desatualizados
  • Exclusão de dados, quando aplicável
  • Informação sobre com quem os dados são compartilhados

Para exercer esses direitos, o contato deve ser feito com a escola responsável pelo cadastro do aluno, ou diretamente com [e-mail de contato].

10. Dados de crianças e adolescentes

O SACP não é utilizado diretamente por crianças ou adolescentes — é uma ferramenta de uso profissional para coordenadores e professores. Os dados de alunos menores de idade são inseridos e geridos pela escola, responsável legal por seu tratamento perante os pais/responsáveis, conforme o Estatuto da Criança e do Adolescente (ECA) e a LGPD.
